# Aside

## What this is

A personal AI copilot for meetings and interviews, for the owner and a couple of friends — not a commercial product. It listens in on a call, gives you private help (suggested answers, notes, context) that only you see, and targets macOS and Windows from one codebase. The macOS app and a Windows x64 installer have been built on the owner's Mac; Windows capture and installed-app behavior still need a Windows runtime check.

The name: a theatrical "aside" is a private remark only the audience hears while the scene carries on. That's the shape of what this app does for you during a call.

## Architecture

- **Tauri** (Rust backend + web frontend), one process, one app, both platforms.
- **Stealth** (default on; screen-share hiding): Aside stays on your display but is left out of screenshots, recordings, and meeting screen-shares (Zoom, Meet, Teams). The Dock icon and the Aside menu-bar menus are hidden too. Activity Monitor still lists the process so you can quit it yourself. Settings is the only on/off. The Stealth indicator follows the saved state (the workspace says "Hidden from screen sharing"). Decorative red gradients and activation pulses were removed at the owner’s request; no decorative delay precedes a confirmed change. Turning it on or off saves the choice and relaunches Aside so Dock and menu-bar policy apply from the first frame. It does not hide the window on your screen. The main window shows only red and yellow buttons (no green button, no full screen). Red quits at once without asking. Yellow hides every Aside window while screen-share hiding is on (Command+H brings them back; that key is claimed only while hidden) and minimizes to the Dock like any app when it is off. The app menu's Quit still asks first. A camera pointed at the screen still sees it.
- `src-tauri/` — Rust. Split by job: `domain/` (sessions), `audio/` (mic + speaker capture, speaking-lights, and laptop-speaker echo cancel on Me only), `stt/` (speech-to-text engines), `pipeline.rs` (live capture → transcription), `conversation/` (both ears, Prepare-only while auto-answer is off), `window_memory/` (Command+Enter conversation windows + session memory), `llm/` (one cloud answer request), `storage/` (SQLite), `commands/` (what the frontend calls: audio, session, stt, llm, documents, capture, rag).
- `src/` — React + TypeScript + Vite, rebuilt 2026-09-25 (branch `redesign-dock`). One bundle, two windows: `main.tsx` mounts the workspace (`home/`) in the normal window and the live call (`live/`) in the second, always-on-top `overlay` window. Folders: `bridge/` (the only place that talks to Rust: typed commands in `api.ts`, event names, shared types), `core/` (pure helpers with tests: tiny store, question detection, answer cleanup/parsing, exports, formatting), `kit/` (buttons, dialog, form fields, toasts, icons), `theme/` (colour tokens for light and dark, base styles), `live/` (the docked call window: a pure state machine `machine.ts`, a controller, and the screens), `home/` (Copilots, Resumes, Documents, History, Settings, plus the pre-call readiness rules). Styling is plain CSS with design tokens; the type is the Mac's own system font.
- **Live window:** reimplemented 2026-10-17 as a charcoal reading surface with solid grey controls, a subdued grey perimeter and no decorative control outlines or section hairlines. Saved Opacity (20–100%) still controls the content background; text and controls stay readable, with a dark text shadow below 75%. The top bar holds the call clock, screen-sharing status, separate capsule mic/speaker buttons, options and a muted red End action. Hearing activity changes the button fill; muted audio keeps a slash and errors use a muted red fill. Answer history lives at the bottom left, with the existing Command+< / Command+> shortcuts. Short / Med / Long remain immediate answer actions in a flat joined grey strip with 11px labels and narrow dark seams; the capsule silver-grey Answer button uses automatic length and stays the same width while busy. A reserved footer keeps them clear of answer text. The question has a rounded grey surface with search/screenshot beside it; only the answer scrolls below, while long questions can scroll within their own space. Search expands a follow-up field; Escape closes it and retains the draft. Answers remain selectable text, lists and code, with retry/settings help on failure. Copy stays on code. The empty state gives one quiet keyboard hint and disappears in short windows. Options retain Opacity, Text size (11/13/15 saved units), Pause listening, Reset window and Open Aside. Menus, recovery details and end confirmation use the same grey control language. Motion uses short fades and immediate press feedback; Reduce Motion removes movement and a reduced-transparency CSS fallback makes the panel solid. All existing resize targets and screen-fit behavior remain. Ending a call still returns to the main app's Call ended sheet; no call-engine, shortcut, saved opacity or data behavior was changed.
- **Workspace design:** refined 2026-10-17 at the owner's request: light workspace and dialogs, softly grey sidebar and fields, a white inset workspace with a 28px rounded frame, thin grey borders, Geist type, dark primary actions and capsule controls. Only the live window stays dark. New Copilot is the first plain navigation link, followed by Library, History and Settings; New Copilot has its own selected state. Saved copilots follow below, with model/speech status at the bottom. The 62px draggable header shows Workspace → current page, protection status and Return to call when needed. The fixed 1000×800 main window stays opaque; small screens use screen-fit safety. Copilot setup is one non-scrolling open vertical form. A compact page title and model selector sit above labelled Company/Role fields; Job description, Documents and Guidance follow vertically. Documents is one rounded grey panel with Resume and Supporting documents side by side. Each has an icon, file details and a trailing Replace/Choose or Select action on the same row; the resume filename opens its preview. Resume is a single replaceable selection with preview; supporting documents use a searchable multi-select popover with checkboxes, counts, Select all/Clear and Add files. Copilot fields use borderless charcoal-grey filled fields (#242424), rounder 18px corners and aligned labels/actions. Hover brightens the fill; keyboard focus and validation retain visible outlines. Job description and Guidance show exactly five short AI summary bullets each, using the existing OpenAI background model. Edit opens the original text; saving refreshes the display summary while the original remains the session context. Exact-source summaries are cached locally per copilot/section and removed with the copilot; errors offer Try again. The summary boxes grow to use available height; file controls stay compact. Save transcript sits bottom left and Start session bottom right. Sections have no enclosing cards or duplicate Edit/Choose actions. Library/History/Settings still scroll when needed. Library and History always expose search for saved items, with Clear/Escape. Shared controls use capsule corners, filled rounded fields and 24px grouped surfaces; page headings share a 26px scale. Preference controls show full model names, call roles have their own line and AI summaries are labelled as overviews. Base page styles load once before the shared refinements, avoiding late style overrides. Library, History, Settings, menus, editors, sheets, dialogs and empty states share the light palette. Navigation collapse, resize, focus and Reduce Motion remain supported. Pages mount immediately with a short fade; sheets use a restrained spring. Branding uses one generated ivory A with a companion stroke on a rounded charcoal tile. The transparent master is public/aside-icon.png; sidebar, restore bubble and favicon share it. scripts/build-icon.swift exports the desktop PNG, ICNS and ICO sizes through Tauri.
- **Retired feature compatibility:** Regular Call was removed at the owner's request (2026-10-14): no navigation row, route, setup/call screens, controller adapter, shared-guidance commands or styling. Old `#/screens` links render Copilots. Existing `kind=screen` records remain readable and hidden; create/update/start reject that retired kind. No database migration deletes old files, history or setup data.
- **Resume quick calls:** Library opens on Resume (tabs: Resume, Other, All). Library uses one toolbar with category and list/grid controls left, flexible space and Search right, above a separate document surface. Each resume’s three-dot menu offers Start quick call without a company or job description. It attaches that resume only, uses the global model and answer rules, records the resolved model for the call, and reuses the existing audio checks/live window. No saved Copilot is created.
- **Pre-call audio checks:** use the saved microphone/output choices, capture locally without transcription, and play a brief low-level two-note chime through the captured output device. Checks run system audio before the microphone, one device at a time to avoid Bluetooth mode-switch races, without decorative delays. macOS plays the default-output chime through its built-in sound player, with cancellation and temporary-file cleanup; custom outputs and Windows retain device-routed playback. Two consecutive measured sound buffers finish a check immediately; quiet input waits at most 2.2s after startup, system audio 1.2s after the chime. The tap warms on its first buffer or a 200ms limit. Meters update at most ten times per second. Failed checks retry only on request, so focus changes cannot silently replay audio. Only measured audio can produce a working check; silence and actual errors offer Retry. Existing active capture is left alone. Native capture startup has an eight-second deadline and runs off the UI thread; test-sound output has a three-second deadline and cancels late playback. These limits prevent a driver problem from freezing the workspace.
- **History:** a Delete all option confirms the number of saved calls, then removes only that snapshot in one database transaction. Active calls are excluded in both UI and storage. Transcripts/answers are removed with their calls; Library files (including older uploads tied to a session) and copilots are kept. Failure rolls back the entire operation.
- **App shortcuts:** only Command+Enter (Answer), Command+Shift+Enter (Screenshot answer), Command+< (previous answer), Command+> (next answer), registered as Command+Shift+Comma/Period. Windows uses Ctrl instead of Command, and its history hints show Ctrl+Shift+Comma/Period. Rust registers them globally. Settings and the live menu share the same four labels. Search opens from the sidebar button. Window menu actions are clickable without extra app shortcuts; standard text editing keys remain native.
- **Dev preview:** `npm run dev`, then open `/?demo=live` (a pretend call; add `&scn=silent|offline|mic` for recovery cards, `&mode=capsule`) or `/?demo#/copilots` (workspace with made-up data). These exist only in development builds.
- Local SQLite (`aside.sqlite3` in the app data directory) is the notebook. Final transcripts are written as they land; a live owner click-through of quit-and-reopen is still owed.
- **Command+Enter** freezes everything spoken since the last press (finals plus the latest interim words); when nothing new has been spoken, it reuses the last window from this session. Every click sends one cloud request: strict rules + cached default documents + compressed memory + that raw window. The screen shows the answer as soon as the first words arrive. Hidden memory updates after. Auto-answer stays off. **Command+Shift+Enter** requests a screenshot answer through the same path as the live camera button. A screenshot is sent to the configured LLM provider's vision endpoint when triggered — same trust boundary as every other answer request in this app, no new provider or new data path.
- No protobuf, no cross-language wire format — it's one process, so plain JSON over Tauri's built-in command/event bridge is the whole data layer.

## Build and app discovery

`./scripts/build-app.sh` leaves one signed, installed-style `Aside.app` at the root and removes the temporary bundle and raw launch binaries. Cargo writes its cache to `src-tauri/target.noindex`, configured in `.cargo/config.toml` so macOS excludes it from Spotlight. The existing local `src-tauri/target` symlink preserves absolute paths saved before the cache was moved; it is ignored by Git and is not a second cache. The build synchronizes the generated bundle into the existing root app directory with `rsync -a --delete`, preserving its file identity rather than deleting/recreating it. It removes obsolete files only inside that generated bundle. The build refreshes only Aside’s app registration and metadata. Saved documents, SQLite, keys and recording permissions are never reset by search cleanup.

## Windows packaging and verification

`npm run build:windows` builds a Windows x64 setup from macOS using cargo-xwin, LLVM/LLD and NSIS, or from Windows with Microsoft C++ Build Tools. The current version is 0.1.5; the result is `release-windows/Aside-Setup.exe`. A fresh install contains no resumes, documents, copilots or call history. Production builds exclude preview sample data; each computer creates its own empty database. Tauri automatically merges `src-tauri/tauri.windows.conf.json`, using a native Windows frame and a per-user NSIS installer. Setup includes WebView2's bootstrapper and a checksum-pinned, Microsoft-signed C++ runtime installer; that shared prerequisite may ask for administrator approval, but Aside installs for the current user. The target is Windows 10 version 2004 or newer and Windows 11. The Windows setup is unsigned.

Windows microphone help opens desktop microphone privacy settings; system-audio help opens Sound settings. Microphone/speaker capture uses CPAL/WASAPI and screenshots use xcap. Default-device auto-follow checks the stable Windows device identity every 500ms while capture is following the system default. Main opens after saved Stealth policy is applied. Native Minimize and Window → Minimize collapse visible windows into a movable 48px bubble. Clicking it restores those windows. Cmd/Ctrl+H explicitly hides Aside; the same key restores it. Closing the workspace or quitting asks first; native overlay close asks to end the call. UTM is installed on the owner's Mac, but no Windows guest has been installed or tested. Browser previews with Windows user agents verify labels/layout only, not Windows APIs.
